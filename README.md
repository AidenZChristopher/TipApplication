-- Overview --
My tip app is a simple android application built using Android 5.0 Lollipop version of Kotlin. The user is promoted to insert the bill amount before then being asked to decide a tip amount. After deciding the tip the user will be allowed to split the bill. Then the total is displayed alongside what each person will pay.

-- Features --
- Rounds dollar amounts to two decimals places.
- Sliding bar to select tip amount
- Dynamic message displaying the quality of tip
  
Improvments: 
- Button displaying tip presets (10%, 15%, 20%)
- Split Bill Prompt
- Total Per Person Label
- Reset to Default Button
